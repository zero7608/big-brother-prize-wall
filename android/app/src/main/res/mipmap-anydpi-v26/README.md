# App icon goes here

`ic_launcher.xml` and `ic_launcher_round.xml` reference an adaptive icon
built from `mipmap/ic_launcher_foreground` and `mipmap/ic_launcher_background`,
neither of which is included in this repository.

To add your own icon: in Android Studio, right-click `res` -> New -> Image
Asset, pick a foreground image, and it generates every density bucket for
you. Delete this README once real icons are in place.

Until then the app builds and installs with the placeholder Android robot
icon.
